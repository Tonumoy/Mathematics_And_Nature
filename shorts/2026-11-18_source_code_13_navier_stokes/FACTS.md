# FACTS (checked 16-17 Nov 2026)
- Navier-Stokes existence and smoothness is a Clay Millennium Prize problem ($1M, list published 2000). Fefferman's official statement allows a smooth external force f in the breakdown statements (C)/(D). Source: claymath.org/millennium/navier-stokes-equation/ (+ Fefferman PDF).
- 8 Sep 2026: OpenAI announced an internal model (~10,000 agents, 88 h) produced a 166-page proof + Lean formalisation of finite-time blowup for the forced 3D NS equations. Sources: AFP/CTV, Anadolu, Scientific American (8 Sep), OpenAI announcement.
- Clay: evaluation "deliberately unhurried"; prize not awarded (Implicator 9 Sep; The Decoder: Clay says "apparently settled", under review).
- 27 Oct 2026: KCL/Cambridge preprint found mismatches between the Lean code and the written proof; it does not show the result is wrong (kcl.ac.uk news).
- Engineers solve NS numerically every day (CFD): aircraft, weather, blood flow.
- Vortex stretching: circulation Γ = ω π r² conserved (Kelvin) -> ω r² = const.
- Poiseuille pipe flow u = U(1 − r²/R²) is an exact NS solution (fastest in the middle).
- On screen we say "OpenAI says its AI proved the maths CAN break (if the fluid gets an outside push)" and "experts: still checking" — never "solved".
