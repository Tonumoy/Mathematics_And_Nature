`_music/` holds the shared music engines (`music_cinematic.py`: dark cinematic score built from the sim's events).

## Conventions

- One folder per Short: `YYYY-MM-DD_slug/`
- 1080×1920, 30 fps, under 60 s; every parameter is a global at the top of the script
- Music is generated by the code itself — no third-party audio
- Rendered videos are not committed (see `.gitignore`); watch them on YouTube

## Setup

```bash
pip install -r requirements.txt
# also: ffmpeg on PATH, fonts-liberation for on-screen text (and fonts-lohit-deva for Devanagari)
```
