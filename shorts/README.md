# Coded Cosmos Shorts

Source code for the daily Shorts on [Coded Cosmos (@cosmoscoded)](https://www.youtube.com/@cosmoscoded). Each folder is one Short: the script that renders the video and its music, the cover generator, and a README with the maths.

| Date | Short | Domain | Watch |
|---|---|---|---|
| 2026-10-23 | [Poets found this before Fibonacci](2026-10-23_pingala_rhythm/) | Math · Sanskrit poetry | [YouTube](https://youtube.com/shorts/6nqwPUfpbro) |
| 2026-10-22 | [This circle is a sound](2026-10-22_lissajous_harmony/) | Math · music | [YouTube](https://youtube.com/shorts/Agl-joxK8Cw) |

## Conventions

- One folder per Short: `YYYY-MM-DD_slug/`
- 1080×1920, 30 fps, under 60 s; every parameter is a global at the top of the script
- Music is generated by the code itself — no third-party audio
- Rendered videos are not committed (see `.gitignore`); watch them on YouTube

## Setup

```bash
pip install -r requirements.txt
# also: ffmpeg on PATH, and fonts-liberation for on-screen text
```
