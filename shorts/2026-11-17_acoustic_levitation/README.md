# SOURCE CODE #12 · Can Sound Lift Water? (acoustic levitation)
Own 3D render of a TinyLev-style single-axis acoustic levitator: 72 ultrasonic speakers at 40 kHz build a standing wave; water drops sit in the pressure nodes every λ/2 = c/2f ≈ 4.3 mm. Loudness dial twist: too soft → falls, too loud → flattens and bursts.
- `render.py` ray-traced water drops (spheroid, Fresnel + ball-lens refraction), painter's-algorithm levitator, standing-wave x-ray, oscilloscope/LED HUD
- `timeline.py` voice-timed beats · `mix.py`, `sfx.py`, `norm.sh` audio (ElevenLabs voice/music/SFX, -14 LUFS)
- `render_part.py` 4K chunked render · `thumb.py` cover · `story.py` Instagram story
